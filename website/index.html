El Problema

Muchos estudiantes de TI
enfrentan una barrera real

Equipos obsoletos, laboratorios costosos y acceso desigual a herramientas practicas limitan directamente el aprendizaje.

La barrera
  • ✕ Equipos de computo obsoletos que no soportan software moderno
  • ✕ Alto costo para actualizar hardware o laboratorios
  • ✕ Desigualdad en el acceso a herramientas practicas
  • ✕ Instalaciones complejas que fallan en Windows
  • ✕ Sin aislamiento entre sesiones de alumnos
La solucion AulaRemota
  • ✓ Todo el procesamiento ocurre en la nube (AWS EC2)
  • ✓ Acceso exclusivo por HTTPS puerto 443
  • ✓ Solo se necesita Chrome o Edge en el dispositivo
  • ✓ GNS3 preinstalado en el servidor remoto
  • ✓ Multi-tenancy: cada alumno tiene su propio VNC

01
Aislamiento de SO
Cada alumno tiene su propio usuario Linux completamente separado.
useradd alumno1 && useradd alumno2
02
Aislamiento Grafico
Cada usuario ejecuta su propia instancia VNC en puertos distintos.
vncserver :1 (→ 5901) · :2 (→ 5902)
03
Aislamiento de GNS3
Archivo gns3_server.conf por usuario con rango de puertos unicos.
~alumnoN/gns3_server.conf → port 308N
04
Aislamiento de Acceso
En MariaDB, cada cuenta web solo puede ver su propia conexion VNC.
GRANT connection_id=X TO alumnoN

Despliegue

El aula entera se levanta
con dos comandos

AulaRemota paso de montarse a mano a estar automatizada de punta a punta. La infraestructura y la configuracion del servidor viven en el repositorio como codigo, en dos capas.

Capa 1 · Infraestructura
Terraform

Toda la infraestructura de AWS esta definida en codigo: se crea entera con un comando y se destruye igual.

  • — Red privada y reglas de cortafuegos
  • — IP fija y registro DNS del laboratorio
  • — La instancia del servidor
  • — Estado centralizado: no depende del ordenador de nadie
Capa 2 · Configuracion
Ansible

Las ~290 lineas de comandos manuales que antes hacian falta ahora estan automatizadas por completo.

  • — Los escritorios remotos de cada alumno
  • — El portal web con su autenticacion
  • — GNS3 configurado por usuario, sin colisiones entre alumnos
  • — La carpeta compartida entre profesor y alumnos
  • — El certificado HTTPS
  • — Contrasenas cifradas dentro del repositorio
$ terraform apply
Red, cortafuegos, IP fija, DNS e instancia listos
$ ansible-playbook site.yml
Escritorios, portal, GNS3, carpeta compartida y HTTPS
# aula completa reconstruida desde cero
$

Escalabilidad

El sistema crece
segun la demanda

Desde pocos usuarios hasta entornos completos de laboratorio. La arquitectura lo soporta.

⇧
Escalado vertical
Aumenta CPU, RAM y almacenamiento en la misma instancia segun la demanda.
⇨
Escalado horizontal
Despliega multiples instancias EC2 para distribuir la carga entre ellas.
⚖
Balanceo de carga
Distribuye las conexiones automaticamente entre los servidores disponibles.
⚙
Orquestacion de contenedores
Preparado para Kubernetes en el futuro, para gestion avanzada de recursos.
